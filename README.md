# Protección de Datos NortiShop

Entrega académica desarrollada por:

- Ariel Van Kilsdonk
- Carlos Orellana

El repositorio contiene las tres actividades del proyecto de Seguridad y Protección de Datos aplicadas al caso de la plataforma de comercio electrónico NortiShop.

## Contenido

- `Actividades/Actividad_1`: mapeo de actores, datos y riesgos CIA.
- `Actividades/Actividad_2`: matriz de cifrado, código fuente, pruebas y evidencia.
- `Actividades/Actividad_3`: informe del Hito 1 en Word y PDF, más la presentación oral.

## Demostración técnica

El código de la Actividad 2 incluye ejemplos de AES-256-GCM, hashing de contraseñas con scrypt, índices ciegos con HMAC y tokenización de medios de pago. Las llaves se obtienen desde variables de entorno y no se almacenan en el repositorio.
